Common targets are:
    obmc-phosphor-image

This template enables the AST2600 DevKit integration layer on top of the
current OCP OpenBMC stack.

Initialize a new DevKit build directory from the OpenBMC repository root with:

    . setup ami-devkit build-devkit
    bitbake obmc-phosphor-image

The equivalent explicit template command is:

    TEMPLATECONF=meta-ami/meta-ami-devkit/conf/templates/default . openbmc-env

The template files are copied only when the build directory is initialized.
Do not run this command from an existing build directory created for another
machine; use a new build directory or update its configuration deliberately.

Do not create an empty `conf/sanity.conf` unless you intentionally want to
bypass the normal OpenEmbedded sanity checks. The upstream `meta/conf/sanity.conf`
contains the actual sanity-check configuration.
